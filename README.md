# 六级背词 · 莫璃（Android）

第一版功能：

- 841 个六级高频词离线词库（来自用户提供的《大学英语六级高频词汇》）
- 每日 30 词目标
- 单词卡：不会 / 模糊 / 认识
- 不会和模糊自动进入复习页
- 本地保存当前进度、今日数量和复习词，不需要账号或联网
- 阅读背词：内置用户提供的《六级模拟卷（四）》完形填空练习
- 原卷未附标准答案，因此阅读页明确标注“答案为 AI 推断”

## 打开方式

1. 用 Android Studio 打开本项目根目录。
2. 安装 Android SDK 35（如果 IDE 提示缺失）。
3. 等待 Gradle Sync 完成。
4. 连接安卓手机或创建模拟器，运行 `app`。

建议使用 JDK 17 或 Android Studio 自带 JBR。

## 技术栈

- Kotlin 2.0.21
- Jetpack Compose + Material 3
- compileSdk / targetSdk 35
- minSdk 26
- SharedPreferences 本地持久化
- 无网络权限、无账号系统、无广告
