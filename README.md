# 六级背词 · 莫璃（Android v0.3）

沿用现有 Kotlin / Compose 工程，保留原词条编号、收藏和复习数据。无账号、无广告、无单词额度限制。背词与已下载阅读离线可用；查词、内容更新及 AI 由用户点击触发。

## 三套可选词库

| 词库 | 词数 | 收录口径 |
| --- | ---: | --- |
| 六级全部词汇 | 5,806 | ECDICT 的 cet4 / cet6 联合词表 5,805 词，加原高频词补充 1 词 |
| 六级高频词 | 841 | 原工程用户提供的高频词表，未重新统计历年真题频次 |
| 六级核心词 | 1,956 | ECDICT 标为 cet6 且未标为 cet4 的六级增量词 |

三套词库相互重叠，不能相加。全库另保留个人词汇、阅读补充词，全局共 5,815 个词条。词表是明确来源的学习集合，不宣称官方穷尽范围。首页和词库页均可切换，分别记住学习位置。复习与收藏跨词库共享，不重复创建学习记录。assume 和 perspective 的原编号保留。

新增数据来自 [ECDICT](https://github.com/skywind3000/ECDICT)，MIT 许可全文随 APK 放在 `assets/ECDICT-LICENSE.txt`。来源版本与 CSV SHA-256 存在 catalog.json；原始 CSV 不打包。生成脚本为 scripts/build_catalog.py，原工程 words.json 未修改。

## 联网查词与内容更新

词库页可本地搜索中文或英文，也可点击「联网查这个英文词」，从 [Free Dictionary API](https://dictionaryapi.dev/) 获取英文释义、例句及来源许可，保存到生词本后可离线学习。已有词条复用原编号；额外在线词条使用独立编号区间。

设置页可联网更新词库。阅读页可下载阅读包。当前更新源为本仓库的公开原始文件，支持随仓库内容迭代更新，并非无限第三方题库。下载完成并校验通过才原子替换本地缓存；失败保留旧内容。词库更新拒绝编号冲突、丢失已有词条及损坏的集合引用。

## 阅读与 AI

- 内置 3 篇原创模拟阅读、15 道四选一题，含答案与中文解析；明确标注非历年真题。
- 支持交卷评分、错题查看、保存最近成绩、重练和难词收藏；未收录难词可转联网查询。
- 保留原版模拟卷选词填空及其 AI 推断答案说明。
- 可选 AI 讲词、文章解析、错题解释，以及用个人生词生成阅读题并缓存。
- 在「设置」输入自己的 HTTPS chat/completions 完整地址、模型和 API 密钥；默认地址为 DeepSeek 官方接口。只在点击请求时向所选服务发送学习输入；外部服务可能计费。
- API 密钥仅留在 ViewModel 内存，不写文件、不进入备份、不打包；重启 App 后需要重新填写。接口地址与模型保存在本机。禁止明文 HTTP、URL 内嵌凭据和携带密钥的重定向。
- AI 生成题明确标注来源；格式校验失败不会覆盖本地题库，原始回答保留供查看。回答达到长度上限会标记可能未完成。

## 学习与发音

每个已学词保存 due（日期）、familiarity（0–5）和 streak（连续认识次数，最多 6）。不会当天重练并归零；模糊次日复习；认识按 1、3、7、14、30、60 天增加间隔。

今日目标可设为 5–200 次。反馈次数包含重复复习，已学词按编号去重。统计包含近七天练习、已学词、熟悉词、生词本和已完成阅读。

使用 Android TextToSpeech 的已安装离线英语语音；手机需预先安装 TTS 引擎及离线英语语音包。未安装时提示，不自动调用在线发音。

## 构建与检查

Android 8.0（API 26）及以上；compileSdk / targetSdk 35；Kotlin 2.0.21、AGP 8.7.3、Gradle 8.9；构建使用 JDK 21，Java / Kotlin 字节码统一为 17。

```sh
./gradlew --no-daemon testDebugUnitTest assembleDebug
```

CI 包含复习调度、词库集合与 ID 保留、阅读包解析、在线词典解析、HTTPS 校验及下载大小边界测试，并在一次性 Android 模拟器运行离线启动、词库切换、反馈和重启持久化检查。scripts/android_smoke.py 会清理模拟器上的测试数据，拒绝在真实手机运行。

Actions 上传两个安装包、单元测试结果和模拟器检查截图：

- `CET6-Moli-v0.3.apk` 保留原包名，供首次安装或签名一致的旧版本覆盖安装。
- `CET6-Moli-v0.3-parallel.apk` 使用 `com.moli.cet6.next`，可与旧版并存，桌面名称显示“六级背词 · 莫璃新版”。旧版 App 及其数据不会被删除；两个包的数据各自独立。

如果你已安装 v0.2，优先用并存版。需要迁移旧版数据时，可在开启 USB 调试并连接电脑后运行 `scripts/migrate_v02.py`；迁移前不会卸载旧版或覆盖目标已有学习数据。

当前为调试 APK，GitHub 临时构建机的签名与已安装 v0.2 不同；原包名 APK 不能直接覆盖安装。并存版可先安装体验，学习记录可按上面的 USB 调试迁移。两个包未来的签名也需保持一致才能直接覆盖升级；后续正式分发需要配置固定签名。真机语音、不同手机界面和真实付费 AI 调用仍需用户环境验证。
